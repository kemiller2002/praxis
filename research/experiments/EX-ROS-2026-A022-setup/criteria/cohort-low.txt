ACTOR-KIND-ANCHOR: ActorKind extension pattern accepts a trailing newline ($ anchor)
  status at baseline: ready; tags: provenance, security

ActorKind.tryParse (src/Ros.Domain/Provenance/Actor.fs) matches ^x-[a-z0-9][a-z0-9-]*$ with a .NET $ anchor, which also matches before a trailing newline, so 'x-agent\n' parses as an extension kind. ATTR-RECONCILE-SYMLINK-SUBMODULE: Content-match symbolic links and submodules for reconciled attribution
  status at baseline: ready; tags: attribution, reconciliation

ReconciliationCoverage hashes working-tree content with git hash-object, which follows symlinks and cannot hash submodules, so a reconciled symlink or submodule path never matches its recorded blob and always fails validation (fail closed). Compare the link target text / gitlink commit instead. Follow-up from GH-80 / DF-ROS-2026-A040.

Acceptance: (1) a reconciled symbolic-link path whose link target is unchanged matches its recorded blob (compare what Git stores for the link, not the followed file); (2) a reconciled submodule path matches when its gitlink commit is unchanged; (3) a changed link target or gitlink still fails closed; (4) regular-file behaviour is unchanged; (5) tests use real Git fixtures for both cases. Not to be merged to main before experiment EX-ROS-2026-A022 is evaluated and the repository owner decides.
