R2 blind implementation quality
-------------------------------
The blind evaluator found two confirmed acceptance defects in each arm.

Grouped (Arm N) was stronger on:
- one reused create/add member-admission rule;
- execution-repository default/enforcement;
- one locked read-decide-write mutation path;
- one group store;
- one common JSON command envelope.

Independent/control (Arm M) was stronger on:
- checkpoint ownership/attribution validation;
- explicit abandoned-member checkpoint classification;
- blank shared-decision rejection;
- deeper checkpoint-corruption tests.

This is a mixed quality result, not a quality sweep. Grouped did not have fewer
confirmed defects by count, but it did show stronger cross-item architectural
cohesion in the dimensions the experiment was designed to test.

Replication against original A021
---------------------------------
The original blind evaluation mapped Arm X to grouped execution and Arm Y to
independent/control after its evaluation. Grouped X used one store, one
member-validation rule, one member classification, one error/JSON style and
one mutation pipeline. Independent Y fragmented the feature across three
stores, two admission rules, two group-ID rules, three member classifications
and multiple rejection/JSON patterns, while retaining stronger fidelity in
several local details.

R2 reproduces that qualitative pattern:
- grouped again produced the more unified cross-item model;
- independent execution again produced stronger detail in some localized
  checkpoint concerns;
- grouped did not show a general loss of acceptance quality;
- R2 additionally measured a large resource advantage.

Original A021 resource telemetry points in the same direction, though platform
cost was unavailable:
- grouped: 114 model requests, 110,627 output, 23,872,205 cache-read, 52 file
  reads, 53 searches, 16 builds, 13 test runs.
- control aggregate: 237 model requests, 176,304 output, 32,211,852 cache-read,
  134 file reads, 159 searches, 34 builds, 15 test runs.

Threats to validity
-------------------
- Same repository, baseline and feature family as the original run. This is an
  execution replication, not an independent-domain replication.
- R2 control deviation C2 matters: GROUP-02 started from a stale baseline and
  initially designed without GROUP-01 before merging it. GROUP-03 also started
  stale but merged prior work before implementation. This can amplify the
  cross-item inconsistency the experiment measures.
- One run per arm does not establish a universal causal law.
- The blind evaluator could not run its own local .NET build/probe/concurrency
  matrix; exact-SHA CI and static review were used as documented.

Classification
--------------
R2 SUPPORTS HY-ROS-2026-A028 for high-affinity work.

The supported mechanism is narrower than "waterfall is better than iterative
development": for a tightly coupled cohort sharing domain invariants and
mutation infrastructure, one context that reasons across the cohort can avoid
repeated context acquisition and reduce cross-item architectural drift.
